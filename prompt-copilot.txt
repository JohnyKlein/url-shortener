Projeto: Enterprise URL Shortener Platform

Crie um projeto moderno de encurtador de URLs com arquitetura baseada em microsserviços utilizando Java 21, Spring Boot 3, RabbitMQ, API Gateway, Redis, H2 persistido em arquivo, CI/CD completo, GitHub integrado e deploy gratuito.
